# ĀRU Intelligence Public Repository Registry

**Last reviewed:** September 7, 2026

This registry explains the intended role of every public repository owned by `aruintelligence`. It is a navigation and maturity guide, not a claim of scientific or production validation.

## Status vocabulary

| Status | Meaning |
|---|---|
| **Profile** | Account-level navigation and institutional identity |
| **Flagship** | Primary public artifact receiving active presentation and documentation attention |
| **Supporting prototype** | Useful standalone experiment related to a flagship program |
| **Canonical index** | Authoritative map for a multi-repository lineage |
| **Historical stage** | Preserved step in an evolving research lineage |
| **Development utility** | Bootstrap, bridge, API, UI, or maintenance component |
| **Early public record** | Older organizational or conceptual record retained for provenance |
