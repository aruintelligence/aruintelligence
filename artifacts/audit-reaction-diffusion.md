# Independent software audit of the 1D memory-field update

**Scope.** This audits the explicit update printed in [How Memory Fields Fix AI Forgetting](https://doi.org/10.5281/zenodo.18010911), §4.1 and Appendix A. It is a test of a *specified numerical toy model*, not a measurement or proof of a physical memory field. The [original transcription](./reproduce_reaction_diffusion.py) uses NumPy; the [audit](./audit_reaction_diffusion.py) independently loops over old cell values using Python's standard library. NumPy is optional for a cross-implementation comparison.

## Reproduce

From the profile repository root, run `python artifacts/audit_reaction_diffusion.py`. A nonzero exit status means at least one check failed. The exact [example JSON report](./audit_reaction_diffusion.json) was generated by that command with Python 3.12.14 and NumPy 2.3.5. Run the command locally to challenge those recorded numbers; the report itself is an editable project-authored file.

The audited synchronous step is

```text
L_i = (mu_(i-1) - 2 mu_i + mu_(i+1)) / dx^2, with periodic indices
S_i = 0.25 exp(-x_i^2/(2*0.8^2)) * (1 - mu_i/2)
mu_i(next) = clip(mu_i + dt*(0.05*L_i - 0.15*(mu_i - 0.10) + S_i), 0, 2)
dt = 0.45*dx^2/(2*0.05); x = linspace(-10, 10, 400)
```

## Checks and observed local output

| Check | What would fail it | Observed local result |
|---|---|---:|
| Periodic diffusion telescopes | A broken neighbor index or boundary rule | `sum(L)*dx = 1.92e-15` |
| First-step mass balance before clipping | A source, decay, or diffusion term implemented differently | Residual `-5.84e-16`; no clipped cell |
| Uniform source-free relaxation | Incorrect baseline or decay sign | Maximum error `0` |
| Saturated source at ceiling | Incorrect source ceiling | Zero at `mu = 2` |
| Independent loop versus NumPy over all 400 steps | An update-order, grid, or implementation mismatch | Maximum absolute difference `1.33e-15` |
| Regression against the original transcription | A change in declared parameters or output | Mean `0.2154056632`; variance `0.0566952393`; sum times `dx` `4.3189105397` |

All six checks passed on the recorded run. As a negative control, changing the decay constant in the audit from `0.15` to `0.16` caused the regression check to fail. The clamp was never exercised in that 400-step reference trajectory, so the trajectory does not test behavior under clipping. At the **same simulated time**, 800 half-size steps differed from the reference profile by at most `0.0001314560`; this is one time-step sensitivity comparison, not a convergence theorem. The paper's inclusive `linspace(-10,10,400)` samples both endpoints while `np.roll` treats them as distinct periodic cells. That convention is preserved exactly here; a mathematical periodic grid would usually omit one endpoint, and sensitivity to that choice remains an open modeling question.

Passing these checks establishes internal software consistency under the stated inputs. It does not establish that μ is observable, that the paper's proposed mechanism explains AI memory, or that the model predicts any measured physical outcome. For empirical probes and null expectations, follow the [Experimental Roadmap](https://doi.org/10.5281/zenodo.18708708).
