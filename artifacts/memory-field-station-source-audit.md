## Public metadata correction

Before review, the record was typed as a *Journal article* without a journal venue, named the creator `Read, Daniel Jacob`, put the topics in one whitespace-packed subject, and described an engineered functioning field node more strongly than the deposit's methods support. The republished record is typed **Publication / Proposal**, and the creator is `Read IV, Daniel Jacob`, matching cover and contact line. Its description leads with the five layers and MFIP steps, identifies sensor integration as future work, and notes the filename discrepancy. Eleven separate subjects now index the actual components and framing: Memory Field Station, Inward Physics, conceptual design, mycorrhizal network, quartz resonance chamber, copper spiral, signal glyph array, Akashic Field, scalar field, interface protocol and bento diagram. Public readback verified the revised type, creator, description, subjects and unchanged file.

The title, December 8, 2025 publication date, English, Zenodo publisher, version `Memory Field Station v1.0 (First Release)`, all-rights-reserved notice, and inherited affiliation were retained. The PDF prints ĀRU Intelligence Inc. but not the inherited geographic detail; that detail merits author confirmation. No ORCID, formal series relation, open license, experimental result or hardware build was inferred.
